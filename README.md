# win2nix

Утилита командной строки, которая приводит текстовые файлы, скопированные из Windows, к Linux-виду:
**UTF-8, переводы строк LF, без BOM**. Один файл на Python 3 (≥ 3.10), только стандартная библиотека.
`dos2unix`, `iconv` и `uchardet` не нужны.

Что делает с каждым файлом:

1. Проверяет, что это текст (сигнатуры PDF/ZIP/EXE/PNG…, NUL и управляющие байты → файл пропускается).
2. Находит BOM (UTF-8 `EF BB BF`, UTF-16/32), считает `\r\n`, одиночные `\r`, хвостовой Ctrl-Z.
3. Определяет кодировку: UTF-8, CP1251 (Windows), CP866 (DOS/OEM), KOI8-R, UTF-16/32 по BOM.
   Файл уже в UTF-8 всё равно проверяется на BOM и `\r`.
4. Убирает BOM, заменяет `\r\n` на `\n`, перекодирует в UTF-8 и записывает результат атомарно.

## Установка

```bash
chmod +x win2nix.py && ln -s "$PWD/win2nix.py" ~/.local/bin/win2nix
```

## Использование

```
win2nix [OPTIONS] PATH...                 # на месте
win2nix [OPTIONS] -o TARGET PATH...       # результат в TARGET (каталог или файл), оригиналы не трогаются
win2nix -c [OPTIONS] [-o TARGET] PATH...  # только отчёт, ничего не меняется
```

| Опция | Смысл |
|---|---|
| `-r, --recursive` | спускаться в подкаталоги (по умолчанию обрабатываются только файлы прямо в каталоге) |
| `-o, --output TARGET` | каталог (существующий или с `/` на конце — будет создан) либо выходной файл (ровно один входной файл) |
| `-c, --check` | показать, что было бы сделано; ничего не писать и не спрашивать; совместимо с `-o` |
| `-f, --from ENC` | задать исходную кодировку принудительно: `cp1251`, `cp866`, `koi8-r`, `koi8-u`, `mac-cyrillic`, `utf-16le`… |
| `-b, --backup` / `-B, --no-backup` | всегда / никогда делать резервную копию при записи на месте |
| `-y, --yes` / `-n, --no` | перезаписывать существующие файлы в `-o` без вопроса / никогда |
| `--touch` | ставить текущее время изменения (по умолчанию mtime, права, владелец и xattrs сохраняются) |
| `-q, --quiet` | только ошибки и предупреждения |
| `-v, --verbose` | печатать и нетронутые файлы, а также детали определения кодировки |

Примеры:

```bash
win2nix notes.txt                      # один файл на месте
win2nix -c -r ~/Documents              # сначала посмотреть, что будет сделано
win2nix -r ~/Documents                 # сконвертировать всё дерево
win2nix -o converted/ -r ~/Documents   # копии в другую папку, оригиналы целы
win2nix -o new.txt old.txt             # в новый файл
win2nix -f cp866 -b *.bat              # принудительно CP866, с бэкапом
```

## Уверенность и резервные копии

Для каждого файла три кандидата (CP1251, CP866, KOI8-R) и, если байты валидны, UTF-8 оцениваются
моделью «насколько это похоже на русский текст» (частоты букв и биграмм, форма слов, регистр).
Разница между двумя лучшими оценками — мера уверенности.

| Уровень | Когда | Что делает утилита |
|---|---|---|
| **sure** | большой отрыв лучшего кандидата (≥ 15 нат), достаточно улик (≥ 24 буквы в словах, ≥ 3 слова), правдоподобные буквы и биграммы и хотя бы два слова из встроенного словаря частых русских слов (одно, если текст преимущественно строчный) | перезаписывает файл сразу |
| **unsure** | мало текста, ЗАГЛАВНЫЕ заголовки, короткие заметки без служебных слов, неожиданные буквосочетания, смешанные кодировки, неопределённые байты | **сначала бэкап** `<имя>.w2n.bak`, потом конвертация лучшей догадкой |
| **unknown** | текст не похож на русский ни в одной кодировке (например, французский в cp1252) | файл не трогается, код выхода 3, подсказка `--from ENC` |

Бэкап не делается, если меняются только BOM и переводы строк (сам текст не трогается). Бэкап никогда
не перезаписывается: при повторной конвертации изменённого файла появится `<имя>.w2n.1.bak` и т. д.
Файлы `*.w2n.bak` и `.w2n-tmp-*` утилита всегда пропускает, даже если их назвать явно, так что
`win2nix *` после первого прогона безопасен.

Файл, в котором к старым строкам в CP1251 дописаны строки в UTF-8 (так бывает после правки в
современном редакторе), помечается как `mixed` и конвертируется построчно, с бэкапом.

## Гарантии записи

- Результат пишется во временный файл рядом и подменяет оригинал через `rename`: прерывание оставляет
  либо старый, либо новый файл, половинок не бывает.
- Бэкап целиком записан и сброшен на диск до того, как оригинал будет изменён.
- Права, владелец, группа, xattrs и время изменения сохраняются (`--touch` обновляет время).
- Символические ссылки не разрешаются и не конвертируются (назовите целевой файл). Жёсткие ссылки
  разрываются: другие имена сохраняют старое содержимое, об этом печатается заметка.
- При `-o` выход никогда не пишется поверх другого входного файла (это ошибка использования, код 2).
- Нечитаемый каталог или файл — ошибка в отчёте и код выхода 3, а не молчаливый пропуск.
- При `-o` существующий выходной файл перезаписывается только после интерактивного подтверждения
  (`y/д`, `n/н`, `a/в` — всем, `q` — стоп). Без терминала и без `-y`/`-n` файл пропускается, код 3.
- Повторный запуск ничего не меняет: все файлы `ok`, бэкапы не плодятся, время изменения цело.

## Отчёт и коды выхода

Строка на файл: `<путь>: <кодировка>[?] [bom] [crlf=N] [cr=N kept] [mac] [ctrlz] -> <действие>`,
где `?` означает уровень unsure. В конце — сводка.

| Код | Когда |
|---|---|
| 0 | всё обработано или уже в порядке |
| 1 | только `--check`: хотя бы один файл был бы изменён |
| 2 | ошибка использования: ничего не записано |
| 3 | хотя бы один файл не обработан (unknown, нет подтверждения перезаписи, ошибка записи…) |
| 130 / 143 / 129 | Ctrl-C / SIGTERM / SIGHUP: временные файлы удалены, печатается частичная сводка |
| 141 | stdout закрыт раньше времени (`… \| head`): тихий выход, записанные файлы целы |

## Ограничения

- Короткие файлы (меньше ~8 слов) и однострочные тексты без служебных слов («и», «в», «не», «что»…)
  получают бэкап — это цена защиты от неверной догадки. На 12 словах уверенность ≈ 93 %, на 20 — 99 %.
- Файл в UTF-8 без кириллицы, но с экзотическими письменностями (китайский, иврит) считается `unsure`:
  текст не перекодируется, правятся только BOM и переводы строк.
- Файлы из одних единиц измерения, чисел с неразрывными пробелами и т. п. в CP866/KOI8-R
  конвертируются как CP1251 (с бэкапом).
- Автоматически распознаются только три 8-битные кодировки из задачи; украинский KOI8-U, CP1125,
  Mac Cyrillic, ISO-8859-5 — через `--from`.
- Файлы больше 64 МиБ не обрабатываются (используйте `iconv`/`dos2unix`).
- Одиночные `\r` внутри файла сохраняются (кроме файлов, где только `\r`, — старый Mac-формат).

## Примеры и тесты

В папке `example/` лежат синтетические файлы в разных кодировках и с типичными «рудиментами»
Windows (CRLF, BOM, DOS-кодировка CP866, KOI8-R): кодировка указана в имени файла. На них удобно
посмотреть, как работает утилита, ничего не меняя:

```bash
win2nix -c -v example/*
```

Тесты работают на копиях этих файлов:

```bash
python3 -m unittest discover -s tests -v
```
